# v0.6-pipeline-bram-isa-tests

## Highlights

- First-cut overlapped educational RV32IM pipeline core.
- Unified 64 KiB BRAM for program/data memory.
- CPU-side MMIO map for LED/switch/demo/test registers.
- AXI-Lite loader/control infrastructure.
- Selected clean-room rv32ui-style and rv32um-style simulation tests.
- cocotb simulation targets and GitHub Actions CI.

## Verification

```sh
make -C sim/cocotb test-all
make -C sim/cocotb test-riscv-smoke
make -C sim/cocotb test-rv32ui
make -C sim/cocotb test-rv32um
```

## Limitations

- Educational project, not a production CPU.
- No full RISC-V architectural compliance claim.
- No official riscv-arch-test/RISCOF claim.
- CSR/trap/interrupt behavior is not claimed unless explicitly documented.
- PYNQ/Jupyter program-loading demo is planned for v0.7.
