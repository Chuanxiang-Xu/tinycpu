# Jupyter Interactive I/O

The current PYNQ/Jupyter flow uses a generic polling-based app I/O layer.
TinyTetris is the first application, but the interface is intentionally not
Tetris-specific.

## CPU-Side App I/O

Programs running on tinycpu use CPU-side dmem MMIO:

| CPU address | Generic name | Compatibility name | Description |
| --- | --- | --- | --- |
| `0x1000_0010` | `HOST_INPUT` | `GAME_INPUT` | Host/Jupyter input bits |
| `0x1000_0014` | `APP_STATUS` | `GAME_STATUS` | App-defined status bits |
| `0x1000_0018` | `APP_VALUE0` | `GAME_SCORE` | App-defined value, score for TinyTetris |
| `0x1000_001C` | `APP_VALUE1` | lines/level | App-defined value |
| `0x1000_0020` | `FRAME_COUNTER` | | App frame counter |
| `0x1000_0024` | `COMMAND_ACK` | | Optional app command acknowledgement |
| `0x1000_0100 - 0x1000_01FF` | `FRAMEBUFFER` | | 256-byte framebuffer |

The CPU polls `HOST_INPUT`; no interrupts are required. The app writes
`APP_STATUS`, `APP_VALUE0`, `APP_VALUE1`, `FRAME_COUNTER`, and the framebuffer.

## Loader-Side Registers

PYNQ/Jupyter uses loader-side AXI-Lite offsets:

| Loader offset | Direction | Description |
| --- | --- | --- |
| `0x10018` | Read | `APP_STATUS` mirror |
| `0x1001C` | Read | `APP_VALUE0` mirror |
| `0x10020` | Read | `APP_VALUE1` mirror |
| `0x10024` | Read | `FRAME_COUNTER` mirror |
| `0x10030` | Write/read | `HOST_INPUT_WRITE` register |
| `0x10034` | Write/read | optional `HOST_COMMAND_WRITE` register |
| `0x10038` | Write | clear host input register |
| `0x10100 - 0x101FF` | Read | packed framebuffer mirror |

In the PYNQ overlay generated by `fpga/vivado/build_pynq_axi_overlay.tcl`,
these offsets are relative to the PS-visible loader base address
`0x43C0_0000`. The notebooks normally discover that base address from the
overlay `.hwh` through `overlay.ip_dict`.

For the complete board build, deployment, and run order, see
`pynqz2_bringup.md`.

Framebuffer mirror reads return packed 32-bit little-endian words:

```text
word[7:0]   = cell n
word[15:8]  = cell n + 1
word[23:16] = cell n + 2
word[31:24] = cell n + 3
```

## Demos

`programs/interactive_demo/` is the generic smoke app. It reads `HOST_INPUT`,
copies the value to `APP_VALUE0`, draws a small bit pattern in the framebuffer,
and writes `TEST_STATUS = 1` when bit 7 is set.

`notebooks/interactive_io_demo.ipynb` demonstrates the same flow from Jupyter.

This interface can support future demos such as Snake, Pong, drawing tools,
sorting visualizations, and benchmark dashboards.
